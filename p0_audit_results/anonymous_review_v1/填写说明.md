# 匿名运动复核

请观看 `videos/R01.mp4` 至 `R18.mp4`，填写 `labels.csv`。所有视频都是轮盘，无需判断目标方向、目标速度或辐条数量是否符合要求；只标注实际可见现象。请在填写完之前不要打开 `mapping_DO_NOT_OPEN_BEFORE_REVIEW.csv`，以免看到来源。

| 字段 | 可填值/含义 |
|---|---|
| object_present | yes / no / unclear，是否能辨认轮盘 |
| dominant_direction | clockwise / counterclockwise / mixed / none / unclear；持续双向且无主要方向用 mixed |
| sustained_change | yes / no / unclear；持续一段时间的主要方向切换，不包括短暂抖动 |
| change_seconds | 可留空；大约时间，可写“约3秒，逆→顺”；多次变化可分号分隔 |
| reverse_jitter | yes / no / unclear；主方向运动中是否夹杂短暂反向抖动 |
| camera_motion | yes / no / unclear；注意整个画面是否转动/平移 |
| wheel_flip | yes / no / unclear；是否翻面或明显改变朝向 |
| structure_stable | yes / no / unclear；辐条、轮毂和形状是否保持稳定，不评价目标数量 |
| observed_spokes | 数得清时填实际根数，否则填 unclear；无需猜测目标根数 |
| uncertainty | low / medium / high，表示你对本条观察的不确定程度 |
| notes | 自由说明停顿、变形、闪烁或其他现象 |

先按原速观看，需要时暂停或慢放辅助辨认；不要将重复纹理的表观速度视为真实转速。无法判断请用 unclear，方向不明确不等于反转。

可以直接在对话中按 R01–R18 报告观察，我会据此录入；未明确观察的字段保留为空，不替你猜测。

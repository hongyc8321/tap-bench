# A0全量VAE缓存资源测试

500个A0视频全部编码成功，未加载Transformer、文本编码器或优化器。固定缓存模型、fp16、VAE切片/平铺；使用当前Dataset解码方法，按训练器方式将分布张量逐属性复制到CPU fp16并常驻，编码输出全部有限。

| 项 | 实测 |
|---|---:|
| 编码循环时间 | 1666.83秒，约27.8分钟 |
| 500条分布张量缓存存储 | 6,739,200,000字节，约6.28GiB |
| 进程最大RSS | 8,478,420KiB，约8.09GiB |
| Torch峰值GPU allocated | 约2.42GiB |
| Torch峰值GPU reserved | 约3.12GiB |

循环时间包含读取和CPU缓存，不含初始数据扫描/模型加载；RSS为进程累计高水位。Torch显存不等于nvidia-smi整个进程显存。缓存字节按每条分布张量去重存储统计，未包含Python对象额外开销。

当前A1/A3各1319行，若继续逐重复条目编码，同形状缓存线性估计为17,778,009,600字节（约16.56GiB），时间粗略为73.3分钟。估计不是实测，快门内容、主机模型驻留和训练并发峰值尚未验证。虽然主机约32GB，不能仅凭A0测试宣布全部臂内存足够。

首次v1因脚本命名profile.py遮蔽Python标准库导入失败，未执行编码。v2改名后成功，日志保留。远端有1小时超时保护和可用主机内存低于4GiB即停止的保护，均未触发。

结束后GPU无计算进程，主机可用内存恢复约31GB。缓存只在进程内存中，未保存供训练复用；没有进行训练更新，也没有自动关机。

建议正式训练前将重复路径的分布编码缓存去重，但保持每次采样独立抽latent；先验证采样语义再优化，不能只复制已抽样latent。A0当前预处理资源已获得实测依据；完整训练峰值仍需单独确认。

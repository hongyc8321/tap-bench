# 不指定辐条数的角向匹配

使用相邻帧环带角向亮度剖面的全圆归一化互相关，不使用目标k，不限制为期望方向。匹配峰低于0.5、与超过5个角度bin之外的竞争峰差小于0.05、往返误差大于2bin或位移近零时标为不确定。阈值为初始诊断规则，未经真实数据校准。单bin为0.5度。

方向平移、反向平移、空白和周期纹理歧义4项合成剖面测试通过。测试只覆盖剖面匹配，不验证整个视频测量链路。往返匹配在这种对称互相关中并非独立证据。

| 样本 | 几何 | 顺时针区间 | 逆时针区间 | 不确定 |
|---|---|---:|---:|---:|
| R12 | 尺寸映射 | 0 | 0 | 48 |
| R12 | 检测中心 | 0 | 0 | 48 |
| R14 | 尺寸映射 | 4 | 0 | 44 |
| R14 | 检测中心 | 21 | 0 | 27 |

每条有48个相邻帧区间。结果表明，当前不指定k的匹配仍无法提供可靠反向证据，且R14的可判定覆盖依赖几何。不确定不是无运动，也不是人工观察错误。

相位法此前为R12提供了一个短时反向候选，本轮匹配没有独立确认它。R14的持续顺转逆仍为人工观察成立、自动未确认的记录，不更改用户标签。

全圆相关对重复纹理可能存在多个等价方向；5-bin峰排除范围也可能使宽峰被视为竞争峰。不能仅放宽阈值以获得更多确定方向，或默认最小位移就是真实运动。本方法仍共享环带几何和亮度表征，不能视为完全独立的物理真值。

建议收敛当前P0：将这两条列为自动时间测量未解决案例，保留人工标签及多种原始信号，不再逐例调参来追求一致。若需要可信的时间真值，应建立可控的已知变向/抖动视频、包含对称与非对称纹理的独立测试集，再评价误报、漏报和拒绝覆盖。现有8 FPS视频无法恢复未采样的连续运动。

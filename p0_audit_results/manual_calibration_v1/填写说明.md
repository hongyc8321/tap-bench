# A0/A3匿名人工校准

本轮24个配对cell、48条匿名视频，编号M001–M048且顺序打乱。按频率与候选覆盖状态分层抽样，但未使用自动候选方向或错误结果选样。它是诊断校准集，不是按总体分布抽样，不能直接用标签比例估计全体模型表现。

请在完成前不要打开mapping_DO_NOT_OPEN_BEFORE_REVIEW.csv和selection_DO_NOT_OPEN_BEFORE_REVIEW.csv。不要通过文件属性、哈希或其他目录反查来源。

## 填写字段

| 字段 | 值 |
|---|---|
| object_present | yes / no / unclear，能否辨认轮盘 |
| dominant_direction | clockwise / counterclockwise / mixed / none / unclear，只标实际表观方向 |
| observed_spokes | 能稳定数清则填整数；变化/太模糊填unclear，并在notes描述 |
| structure_stable | yes / no / unclear，轮毂、辐条、轮圈是否保持结构 |
| blur_level | none / mild / strong / unclear，指妨碍纹理辨认的模糊程度，不推测快门来源 |
| sustained_change | yes / no / unclear，是否有持续主方向切换 |
| change_description | 如“约3秒顺→逆”，没有填not_applicable，无法定位填unclear |
| reverse_jitter | yes / no / unclear，主方向中夹杂短暂反向运动 |
| camera_motion | yes / no / unclear，整体视角/相机是否运动 |
| wheel_flip | yes / no / unclear，轮盘是否翻面或明显改变朝向 |
| measurement_usable | yes / no / unclear，你认为仅凭画面能否可靠判断主方向；不评价自动算法 |
| uncertainty | low / medium / high，你对整条标签的主观不确定性 |
| notes | 停顿、速度不稳定、局部变形、数量变化等 |

方向变化时dominant_direction填写占时更长/更明确的主方向；无法确定主导方向用mixed或unclear。看到表观顺/逆即可，不需要估计物理连续方向或目标速度，不猜目标辐条数。

建议先原速观看，需要时慢放一次。若慢放改变你的方向判断，填unclear并记录。不要因为轮盘模糊就自动填measurement_usable=no；如果主方向仍明确，可以填yes并把blur单独标注。

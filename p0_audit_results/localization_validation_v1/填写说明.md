# 定位验证：只看形状，不判断方向

本轮冻结定位器阈值。8个新cell，每个取首、中、末帧，共24张；排除先前人工审核/故障诊断cell，但仍来自已经自动测量过的实验池，不是全新数据集。

请先看每组V01_contact.png至V08_contact.png的三帧总览，必要时打开对应raw原图和overlay叠加图。在labels.csv填写：

| 字段 | 填写值 |
|---|---|
| visible_wheel | yes / no / unclear，是否可见轮盘 |
| near_circular | yes / no / unclear，整体外形是否近圆形 |
| center_alignment | good / bad / unclear / not_applicable，红十字是否位于轮心；rejected没有十字填not_applicable |
| outer_radius_fit | good / too_large / too_small / unclear / not_applicable，绿圈是否贴近轮盘外缘；rejected填not_applicable |
| notes | 遮挡、透视、没有外圈、轮心歧义等现象；不要根据运动方向判断定位 |

可以直接按V01–V08在对话中描述三帧的结果；三帧不同请注明第几帧。无需量像素，不需要观察转速/方向。该环节验证可用性和拒绝行为，不能替代精确轮心/半径真值误差评估。

## 自动检查结果

固定阈值下，54个不同背景亮度/前景对比度/半径/偏心的合成轮盘中24个被接受。它对较暗背景、较浅轮盘或小尺寸案例存在拒绝，具体见stress_tests.csv。这个数字不是准确率：本方法明确限制适用场景，压力测试包含范围外输入。

两个圆形干扰案例（实心圆和空圆环）均被接受，证实定位器只检测近圆外轮廓，不能判断它是否具有可测辐条。不得把accepted当作“有效运动测量样本”。

新24帧中21帧被接受、3帧拒绝，尚需人工标签才能判断定位与拒绝是否合理。阈值未根据这些结果调整。此次只使用本地数据。

# 新评测链路 v1 发布

状态：全量执行和数据契约已完成；这是冻结的保守表观方向评测协议，不是已证明物理正确的运动测量器。没有重新训练、重新生成模型视频或连接云端。旧结果不覆盖。

## 运行范围与规则

1182条CogVideoX轮盘：标准原模型及七个训练评测组各141条，顺时针对照ORIG/A0/A5各18条。LTX/Wan/Seedance和栅格不在本版范围。

入口p0_evaluate_v1.py；以--out指定新目录重复运行，已有目录拒绝覆盖。protocol.json记录固定参数、源码hash、依赖版本、快照清单hash；每条结果记录视频hash。

流程：完整解码与FPS检查 → 每帧保守轮廓定位 → 中心/半径漂移检查 → 首帧固定几何的圆形/椭圆与五种中心偏移共10个变体 → 越界、振幅、方向一致性及最小SNR检查 → 1.5秒窗口两种几何的共同方向检查。

仅窗口覆盖至少50%、没有反向窗口混合、局部与整段一致时输出accepted_apparent_direction。其他样本保留拒绝原因。后续门槛在前置拒绝时不执行，主状态是首个阻断项，不是独立风险发生率。

定位不验证辐条身份。首帧固定中心没有追踪每帧运动；半径范围25%–85%、5像素扰动、5%漂移门槛与SNR=5均为本版冻结工程规则，尚未经独立总体校准。时间双向候选不是人工确认的持续变向，短暂抖动检测不在本版正式输出中。

固定seed=1931，10000次逐cell配对bootstrap，未做相关参数cluster bootstrap或多重比较校正；区间不包含几何/方向估计系统误差及训练随机性。无变异或样本不足的区间记null。2+频段和顺时针对照另见paired.json。

不能据此宣布A2/A3达到原方案成功标准：没有可靠f*50、高频独立质量指标，训练数据本身也不是严格配对。新旧符号与排序差异再次说明旧几何RR不可用于机制结论。

## 交付

- rows.csv及每组CSV：完整输入分母与状态。
- geometry_variants.csv：执行到该阶段的10种采样估计。
- temporal_windows.csv：执行到时间阶段的窗口方向。
- summary.json、paired.json：分组覆盖、条件分数、配对差异及区间。
- protocol.json：版本、参数和来源。
- test_p0_evaluate_v1.py：规则边界与已发布分母/配对交集检查。

本版完成了可执行、可追溯的新评测链路收尾，但“物理混叠基准科学验证完成”与“训练成功”均不成立。后续改规则必须新建版本并重新验证，不能静默更改本版分母或覆盖原人工标签。

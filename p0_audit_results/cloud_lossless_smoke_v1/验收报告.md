# 无损数据云端兼容性验收

从正式FFV1/AVI数据集中选取B00000/B00001各point/shutter180，共4个视频。放入独立/home/ubuntu/nkst_lossless_smoke_v1目录；数据目录名A0仅为测试入口路径，本测试混合两种处理，不是正式A0实验。

这是格式兼容与训练功能检查，不是全量训练或效果验证。未验证500条完整VAE缓存的时间/内存、全部臂的采样和正式训练预算。没有下载模型，未改动历史权重，未执行服务器关机。
